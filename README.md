A hands-on exploration of reinforcement learning fundamentals.

This Project was completed as a part of ERC club assignment. 
The main goal was to understand the core ideas behind rl by implenting the underlying algorithms and applying them to a path-planning program.

The main topics explored were:

  Markov Decision Processes (MDPs)
  States, actions, rewards, and transitions
  Value functions
  Bellman equations
  Dynamic programming
  Iterative value updates
  Policy extraction

Although this is a relatively small project, it represents an important step in understanding reinforcement learning from first principles.
